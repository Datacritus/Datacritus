# Source identification assets

Original provider marks downloaded from the providers' own websites, recorded with original URLs and SHA-256 hashes in provenance.json. OECD's SVG is the inline header mark on its official homepage. Assets are embedded in the built landing page, with no visitor request to a third-party image host. The marks identify credited data providers and do not imply endorsement or partnership. Ownership remains with the respective organisations.

Penn World Table is shown as a plain typographic dataset label rather than an invented institutional logo. The UNESCO UIS mark is white; its tile provides a dark background without recolouring the asset. Provider counts are generated from the published catalogue and group the World Bank's WDI and WGI feeds together. Only providers present in the catalogue appear; OWID and candidate providers are not listed.
